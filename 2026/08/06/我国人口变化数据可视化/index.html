我国人口变化数据可视化

我国人口变化数据可视化

不记得哪一天了，读到

  • 知乎原文
  • 知乎原文

两篇文章，都提到我国人口变化的趋势，尤其是人口数量与增长率的变化。为了更直观地理解这些数据，我决定使用Python进行数据可视化。

STEP1 国家统计局「人口-总人口」数据获取（retrieve_data.py）

目标

从 https://data.stats.gov.cn/dg/website/page.html#/pc/national/yearData 自动获取
年度数据 → 人口 → 总人口 的全部指标数据（1949 年至今，结束年份默认为当前年份前一年），保存为 data.csv。

站点结构分析

data.stats.gov.cn/dg 是国家统计局 2024 年后上线的新版数据门户，是一个 Vue 单页应用（SPA）：

  • 页面 HTML（page.html）只是一个空壳（<div id="app"></div>），所有内容由 JavaScript 渲染；
  • 数据通过 AJAX 接口动态加载，直接抓取 HTML 拿不到任何数据；
  • 主要 JS 包：static/js/project/dsf-pc.js、subPage.js、dsf-vendors.js、
    modules/dataview/js/dsf-dataview.common.js 等。

发现接口的方法

  1. 用 curl 拉取页面 HTML，确认是 SPA 空壳；
  2. 下载全部 JS bundle，用正则搜索 api、query 等关键词，定位到数据接口域名路径；
  3. 用 Puppeteer（无头浏览器）打开真实页面：
    • 点击指标树「人口」→「总人口」；
    • 在页面上下文中注入 fetch / XMLHttpRequest 钩子，捕获真实的网络请求；
    • 拿到接口 URL 与请求体格式；
  4. 用 curl 直接重放请求，验证接口可用并可返回更大年份范围。

注：旧版门户接口 data.stats.gov.cn/easyquery.htm 已被 WAF 拦截（HTTP 403，UrlACL 规则），
且页面提供的年份选择器只有「最近 5/10/15 年」，直接改接口参数即可获取全量历史数据（默认截止当前年份前一年）。

关键接口

1. 指标树查询（GET）

  • pid 为空 = 根节点；code=3 = 年度数据目录；
  • 返回节点数组，含 _id、name、type、isLeaf 字段。

注意：节点 ID 是站点内部生成的 UUID，会随站点改版变化，因此程序必须动态发现而不是写死。

2. 指标列表查询（GET）

3. 数据查询（POST，核心）

请求体：

要点：

  • dts（时间范围）格式："起始YY-结束YY"，如 "1949YY-2025YY"，支持全量年份；
    而页面上只有「最近 5/10/15 年」选项，这是直接调接口的最大优势；
  • das 为地区维度，000000000000 表示全国；
  • 响应：{"data": [{"code": "2025YY", "name": "2025年", "values": [{_id, _name, value, ...}]}, ...]}，
    每年一个对象，values 内按指标 ID 对应数值。

数据处理与校验

  1. 解析：按年份遍历 data 数组，用指标 _id 建立 年份 → 各指标数值 的映射；
  2. 排序：年份升序（接口返回为降序）；
  3. 交叉校验（程序内置，仅警告不阻断）：
    • 男性人口 + 女性人口 = 年末总人口；
    • 城镇人口 + 乡村人口 = 年末总人口；
    • 1962 年存在官方舍入差异（34517+32778=67295 vs 67296，差 1），为源数据特性；
  4. 写出：data.csv，UTF-8 带 BOM（Excel 可直接打开不乱码），
    表头 年份,年末总人口 (万人),男性人口 (万人),女性人口 (万人),城镇人口 (万人),乡村人口 (万人)。

数据口径说明（官方）

  • 数据范围：1949 – 2025 年（77 年 × 5 指标 = 385 个数值，无缺漏）；
    结束年份由程序按「当前年份 − 1」动态计算，站点数据更新后范围会自动延伸；
  • 1981 年及以前人口数据为户籍统计数；1982、1990、2000、2010、2020 年为人口普查数据推算数；
    其余年份为年度人口抽样调查推算数据；
  • 总人口和按性别分人口中包括现役军人，按城乡分人口中现役军人计入城镇人口；
  • 年末人口数指每年 12 月 31 日 24 时的人口数；全国人口总数未包括港澳台及海外华侨。

复现

程序特点：

  • 纯 Python 标准库（urllib），无需安装第三方依赖；
  • 动态发现指标树，站点改版更新节点 ID 后仍可运行；
  • 请求带 User-Agent / Referer，失败自动重试（3 次退避），请求间有 0.3s 间隔防限流。

1. 任务与输出文件

数据来源：data.csv（1949—2025，共 77 年，单位万人）。

2. 核心实现要点

2.1 数据读取

  • csv 模块读取，编码 utf-8-sig（带 BOM）。
  • 人口单位为「万人」，与 data.csv 一致。

2.2 增长率

首年（1949）无环比数据，记为 None，作图时剔除。

2.3 统计信息（平均值 / 方差 / 标准差）

  • 采用总体统计（分母为 N）：statistics.mean、pvariance、pstdev。
  • 统计区间 = 图中展示的年份区间。首年无增长率，实际统计年份比标题多展示一年（如总人口图标题 1949—2025，统计为 1950—2025）。
  • 2020 以来的增长率用 2019 作为基线（growth_rate(male)[i20:]，i20 为 2020 的索引）。

2.4 增长率图用柱状图（直方图）

  • 需求：「增长率图改为直方图」。
  • 实现：ax.bar(xs, ys, width=0.8, color, alpha=0.88) + axhline(0) 零增长参考线。
  • 统计框：右上角 text(0.985, 0.975)，bbox 圆角白底描边。

2.5 人口数量图 Y 轴从 0 开始

  • 需求：「避免产生从 0 开始或下降到 0 的错觉」。
  • 实现：annotate_peak 中 set_ylim(0, max*1.12)，峰值标注放在 max*1.055 高度处；峰值位于左 1/3 时标签放右侧，否则放左侧，避免遮挡。
  • 用 FuncFormatter 给 Y 轴刻度加千分位（72,357）。

3. 断轴图（任务 7、8）——重点与踩坑

2020 以来数据区间极窄（男性 71,685—72,357，女性 68,804—68,969），若沿用 Y 轴从 0 开始的整段坐标，数据会压成一条直线。解决方案：断轴图。

3.1 结构（两段堆叠子图）

  • 子图参数：plt.subplots(2, 1, sharex=True, figsize=(10,6), dpi=150, gridspec_kw={"height_ratios":[5,1]})
  • 数据面板 ylim = (min-pad, max+pad)，pad = 区间跨度 × 0.18；基线段 ylim = (0, 数据面板下缘)。

3.2 断轴绘制

  • 隐藏内侧脊线：ax_data.spines["bottom"] 与 ax_base.spines["top"] 都不可见。
  • 斜线标记：plot([0,1],[0,0], transform=transAxes, marker=[(-1,-0.45),(1,0.45)], clip_on=False)，上下两段各画一条。

3.3 刻度与格式

  • 数据面板用 FixedLocator 手动定刻度，步长从 (50, 100, 200, 500) 中取「能容纳 ≤5 个刻度」的第一个；刻度值保证落在面板内。
  • 基线段只标 0，用 FuncFormatter 加千分位。
  • X 轴用 FixedLocator(years) 精确锁定数据年份。

3.4 踩坑记录（按修复顺序）

  1. 直线问题：整段 0 起点坐标轴导致窄区间数据压成直线 → 改为断轴。
  2. 零刻度位置反了：最初基线段在上、数据在下，零刻度线出现在 72,400/68,975 的上方（读法违反直觉）→ 交换面板顺序，数据在上、0 基线在下。
  3. 越界刻度：MaxNLocator 生成了面板外的刻度（71,500/72,500 等），标签渲染到面板外面 → 改用 FixedLocator + 自算步长。
  4. 年份标签位置：年份最初在顶部数据面板（断轴上方），随后又出现 2019/2026 越界年份 → sharex=True 把 X 标签放到最底部的 0 基线段，年份最终落在断轴之下、图的最底部。
  5. 断轴下方无填充：浅色填充只画在数据面板（填到数据面板下缘），断轴以下视觉断开 → 基线段补一条 fill_between(years, y_data[0], 0, alpha=0.10)，与上方填充在断轴交界处无缝衔接。
  6. 数据线裁剪残迹：曾尝试在基线段画数据线，因数据在视野外留下 1px 抗锯齿残迹 → 基线段不画数据线，只画整片填充。

3.5 逐年数值标注（最终需求）

  • 需求：「折线标记每年的具体人数，而不是只标 2020 年的」。
  • 实现：去掉单点峰值箭头标注，遍历每年画圆点 plot(xi, yi, "o", markersize=4.5) + 数值标签 annotate(f"{yi:,.0f}", xytext=(0,6), textcoords="offset points", ha="center", va="bottom", fontsize=9)。
  • 标签置于数据点正上方 6px，避免遮挡折线与刻度；相邻年份间隔大（≈260px），6 个标签不重叠。

6. 验证方法

底层模型不具备原生识图能力，因此采用以下间接验证手段：

  1. 结构验证（文本级）：matplotlib 图对象直接检查——文本列表、圆点数、断轴基线段文本是否为空、刻度位置等（比像素精确）。
  2. 像素验证（PIL）：Image.open + 逐像素扫描，检查系列色像素是否全部落在数据面板内、基线段填充平均色是否符合「表面色 × 0.9 + 系列色 × 0.1」的预期混合、年份标签是否位于最底部。(deepseek没有原生视觉识别)
  3. 独立重算：用 numpy 重新计算统计值，与图内统计框核对（保证统计口径一致，如 2020 的增长率以 2019 为基线）。
  4. 字体警告检查：脚本 stderr 无缺字警告即中文字体正常。

7. 复现方式

依赖：Python 3.13+、matplotlib 3.10+、Pillow（仅验证用）、SimHei 字体。
