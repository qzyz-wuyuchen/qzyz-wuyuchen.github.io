Hexo 博客文章发布与维护技术文档

本文档基于 Hexo + GitHub Pages 环境，详细说明博客文章的创建、编辑、发布、更新及删除等完整生命周期操作。适用于已搭建好 Hexo 博客的维护者。

1. 前置条件

  • 本地已安装 Node.js、Git 和 Hexo CLI。
  • 博客项目已初始化，并与 GitHub Pages 仓库关联完成。
  • 基础命令可在终端正常执行。

若尚未搭建环境，请先参考 Hexo 官方文档完成基础搭建。

3. 编辑文章内容

使用 Markdown 编辑器打开生成的 .md 文件，在第二个 --- 下方编写正文。

3.1 Front-matter 常用字段

| 字段 | 说明 | 示例 |

|——|——|——|
| title | 文章标题 | 我的第一篇文章 |
| date | 发布日期，格式 YYYY-MM-DD HH:mm:ss | 2026-07-11 08:30:00 |
| tags | 标签，支持数组或逗号分隔 | [Hexo, 教程] |
| categories | 分类 | 技术 |
| permalink | 自定义文章永久链接（可选） | /my-custom-url/ |

添加 permalink 后，文章访问地址将固定为此值，不受后续修改日期或标题的影响。

7. 删除文章

  1. 进入 source/_posts/ 目录，找到对应 .md 文件并删除。
  2. （可选）若存在草稿 source/_drafts/ 中的同名文件，一并删除。
  3. 执行重新生成和部署，远程站点的文章页面即被移除。

删除后，原文章 URL 将无法访问，如有需要可提前设置重定向。

8. 常见问题

Q1: 文章底部链接显示 http://example.com/…

原因：站点根配置 _config.yml 中 url 仍为默认值。将其修改为 https://你的用户名.github.io 并重新部署即可。

Q2: 修改日期后旧链接失效怎么办？

如上文所述，为文章设置固定的 permalink 可防止链接变化。对于已失效链接，可考虑使用插件（如 hexo-generator-alias）进行重定向。

Q3: 如何批量修改多篇文章？

可直接在 source/_posts/ 中使用文本编辑器的批量替换功能修改 Front-matter，完成后重新生成部署。务必提前备份。

9. 日常操作速查表

| 操作 | 命令 |

|——|——|
| 新建文章 | hexo new "标题" |
| 本地预览 | hexo server |
| 生成并部署 | hexo clean && hexo g && hexo d |
| 仅生成静态文件 | hexo clean && hexo g |
| 删除文章后更新 | 手动删除文件，再 hexo clean && hexo g && hexo d |
